# Задание для Codex

Опубликуй предоставленный статический сайт «Анна · Искусство гармонии» на GitHub Pages.

- **Не переделывай дизайн** и не меняй утверждённые тексты, порядок карточек, фотографии, цвета или типографику.
- Используй существующий `index.html` и все файлы в `assets/` без сжатия с потерей качества. Изображения должны открываться локально и после публикации, без внешних ссылок.
- Не используй React, Vite, npm и сторонние фреймворки: сайт уже готов.
- Сохрани работу нативных раскрывающихся разделов `<details>` и переходов из карточек содержания к соответствующим разделам.
- Проверь адаптивность для iPhone: заголовки без разрыва на колонки, читаемый текст, сетка карточек на мобильном в один столбец.
- Если GitHub подключён и есть разрешение на создание репозитория, создай новый репозиторий `anna-iskusstvo-garmonii` и настрой GitHub Pages на ветку `main`, корень репозитория. Не изменяй другие существующие сайты или репозитории.
- Если публикация требует авторизации, настройки видимости или согласия на публичное размещение реальных фотографий, запроси подтверждение пользователя перед публикацией.
- После публикации сообщи точную рабочую ссылку и проверь загрузку изображений и интерактивность.
